Supernova NYC · Internship Work

Supernova — Web Design & Development

During my internship at Supernova NYC, I designed, built, and refined 20+ pages across the studio’s Webflow website. Working within an existing visual system, I created new layouts, developed responsive experiences, and adapted project content across desktop, tablet, and mobile.

Role UX & Web Design Intern
Tools Webflow · Figma · HTML/CSS
Focus UX · UI · Web Design · Responsive Design
01

Designing within an established visual system

Rather than redesigning Supernova’s existing identity, my role was to extend it. I worked within the studio’s established typography, navigation, spacing, and visual language while creating new page structures and adapting layouts for different types of content.

02

Supernova Room — from structure to launch

I built the Supernova Room page from the ground up in Webflow, using the studio’s existing design system as a foundation. I developed the page structure, content hierarchy, booking section, imagery, and responsive behavior while maintaining consistency with the rest of the Supernova website.

04

Adapting content to the visual system

Some project assets required custom visual treatments rather than simply being placed into an existing template.

Custom Media Treatment

Kiehl’s Supersucker

The original vertical video did not naturally fit the site’s horizontal project format. I created a custom background treatment using the original video imagery, a translucent green overlay, blur, and graphic elements inspired by the project itself.

This allowed the media to preserve its original proportions while feeling intentional and visually integrated into Supernova’s existing design system.
